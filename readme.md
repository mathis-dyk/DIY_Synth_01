# DIY_Synth_01

Homemade Synth to discover how does this works.
The goal is to reproduce something small as a KORG NTS1 MK2 to plug it in the PO-33 while I travel.
The ribbon controller comes from an old SAMSON Graphite M25.
The goal is to have 3 independant oscillators, multimode filer, 3 LFOs, arpeggiator (lol on a ribbon will be fun), and FX chain.

## Hardware

- Teensy 4.1
- PCM5102
- SSD1309 OLED 2.4
- 1 rotary encoder (will be 6)
- 5 Potentiometers 100K (will be 0)
- 10 tactiles buttons with LED (10 ??)
- Ribbon Controller
- Audio OUT 3.5mm
- MIDI USB
- Pocket operator sync IN/OUT
